# ひらがなよめ丸（あ行編）

## うごかしかた
```
npm install
npm run dev          # 開発サーバー（スマホからは https が必要：マイク利用のため）
npm run build        # dist/ に公開用ファイル
npm run build:single # dist-single/index.html の 1 ファイル版
```

## カードの文字（UDデジタル教科書体 NK-B）
- カードの文字・なぞり書きのお手本・文字カードはすべて UDデジタル教科書体 NK-B で描画します（src/index.css の `--font-card`）。
- Windows 10/11 には標準で入っているので、そのまま使われます。
- iPad など入っていない端末では、右上「カード とうろく」→「フォントを登録」から、ライセンスをお持ちのフォントファイル（.ttf/.otf）を登録すると、その端末に保存されて使われます。
- どちらも無いときは Klee One（教科書体風）で表示します。

## カード画像
- 既定の絵は、添付カードから文字を取り除いた線画（src/assets/cards）。その上に NK-B の文字を重ねています。
- 「カード とうろく」で各文字の PNG を差し替えられます（IndexedDB に保存）。差し替えた画像は文字入りの想定なので「文字を重ねる」は最初オフです。

## こえ（ずんだもん）
- ひらがなの読み上げと、ほめことば（「ごうかくなのだ！」「クリアなのだ！すごいのだ！」）は、VOICEVOX のずんだもん（ノーマル）で作った音声ファイルです（src/assets/voice）。
- 端末の音声合成に頼らないので、どの端末でも同じ声で鳴ります。音声ファイルが鳴らせないときだけ、端末の音声合成に切り替わります。
- iPad/iPhone では、消音スイッチがオンでも鳴るように設定しています（Safari 16.4 以降）。
- ずんだもんの利用規約により、クレジット「VOICEVOX:ずんだもん」の表記が必要です。ホーム画面の下に表示しています。消さないでください。
